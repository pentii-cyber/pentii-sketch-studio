# PENTII Sketch Studio

Browser-based 3D house sketch editor for managers. Open index.html through the published GitHub Pages link. No installation or account is required.

Projects are saved in the current browser. Use the project download and open controls to keep an editable copy or transfer it to another computer. The application can produce visualizations and sketch PDF albums.

Photo and floor-plan recognition is not connected in this static release. This repository contains only public browser assets, not the local API server or credentials.

See guide.html for the Russian manager guide.
